Claude Time is relative (to you) · how it works

Your past tasks time your next one

Claude Code already keeps a transcript of every session on your machine. task-eta reads them, measures how long each task really took, and turns that into an estimate Claude writes before it starts.

Your machine · nothing leaves it
01

Measure

Each prompt you typed plus all the work it caused is one task, timed from the prompt to the last action. Time spent waiting for your answers does not count.

02

Sort

Every task gets a kind of work by how much it did. Each kind takes 3 to 5 times as long as the one before.

Re-time

Claude Time is relative (to you) · privacy

It learns from you. It tells no one.

The first run asks before it reads your past sessions. Everything it learns stays in one folder you can delete.

Reads

on your machine
  • The transcripts Claude Code already keeps: ~/.claude/projects
  • Only after you say yes. Say no and it starts from today.
  • On a Mac, from the Claude desktop app's own files: the model, effort and title of each session

Writes

one folder
  • ~/.claude/task-eta/: task times, the first 300 characters of each prompt with keys masked, model, effort. Private to your user
  • Two hooks (four more with the widget) and an optional rule, each file backed up first
  • All removed with --uninstall --purge

Never

by design
  • No network code. Python standard library and a Swift app, nothing that sends.
  • No telemetry, no account. The author receives nothing, ever.
  • No downloads. The widget is built on your Mac from the source you can read.
Good to know: to help Claude pick the kind of work, the hook lists up to 5 of your similar past requests from the same project by kind, time and tool calls only. No text of a past prompt goes into a new one: snippets of your prompts show only where you look for them, in the report, the status and the widget.
